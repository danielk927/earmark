# RC522 (MFRC522) on ESP32

- Library: `MFRC522` (Arduino Library Manager), version 1.4.12 installed here; source https://github.com/miguelbalboa/rfid, header https://raw.githubusercontent.com/miguelbalboa/rfid/master/src/MFRC522.h.
- Constructors: `MFRC522()`, `MFRC522(byte resetPowerDownPin)`, `MFRC522(byte chipSelectPin, byte resetPowerDownPin)`; `PCD_Init()` overloads take the same pins.
- `PCD_ReadRegister(MFRC522::VersionReg)` returns 0x00 or 0xFF when no reader answers; used as a health check.
- `PCD_SetAntennaGain(MFRC522::RxGain_max)` (48 dB) for the best range.
- `PICC_IsNewCardPresent()` only reports *new* cards (REQA); a tag that stays on the reader after `PICC_HaltA()` is not reported again.
  For continuous presence, call `PICC_WakeupA(atqa, &len)` (WUPA also wakes halted tags), then `PICC_ReadCardSerial()`, then `PICC_HaltA()`.
- `uid.size` is 4, 7, or 10 bytes; `uid.uidByte[]` holds the UID.
- StatusCode values include `STATUS_OK`, `STATUS_COLLISION`, `STATUS_TIMEOUT`.
- Multiple readers on one SPI bus: drive every chip-select pin HIGH before initializing any reader; a shared RST pin works because `PCD_Init` only hard-resets when RST is low, otherwise it soft-resets.
- The RC522 is a 3.3 V part; power it from 3V3.
- UNVERIFIED: whether 6 readers at max gain need more than the DevKit's 3V3 regulator in practice (about 13-26 mA each per common datasheets).
